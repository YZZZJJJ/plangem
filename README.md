# PlanMate：计划制定与打卡网页

这是一个可运行的全栈原型，包含：

1. **个人界面**
   - 首次进入注册唯一用户ID和密码
   - 创建计划
   - 设置开始日期、打卡间隔、结束日期
   - 计划详情页进行打卡
   - 支持图片/常见办公文档/PDF等附件
   - 查看历史打卡记录

2. **关注界面**
   - 通过用户ID搜索其他用户
   - 关注用户
   - 查看其公开计划
   - 对计划发表评论
   - 发送“催促”

3. **日历界面**
   - 根据开始日期 + 打卡间隔自动计算应打卡日期
   - 点击具体日期弹窗查看当天任务
   - 已完成任务显示 ✓

## 本地运行

建议 Python 3.10+。

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

然后打开浏览器访问：

`http://127.0.0.1:5000`

## 数据

默认使用 SQLite，数据库文件会自动生成 `app.db`。
上传文件保存在 `uploads/`。

## 生产环境建议

这个原型适合课程设计、作品集展示和功能验证。若正式部署，建议继续增加：

- PostgreSQL / MySQL
- CSRF 防护
- 更严格的文件类型和病毒扫描
- 云存储
- 邮箱/手机找回密码
- 计划隐私设置
- 评论删除与举报
- 消息通知
- Redis / Celery 定时提醒
- HTTPS
- Nginx + Gunicorn
